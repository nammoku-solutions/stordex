# Stordex

## 1. Overview

This section describes the purpose and value of the system.

This system integrates order management and inventory management into a single cloud-based web application designed for logistics and wholesale businesses. By migrating from a local environment to the cloud, the system improves scalability, availability, and maintainability.

---

## 2. Benefits

This section outlines the key benefits of implementing the system.

### Efficiency

The system unifies order and inventory management, reducing manual work and duplicate data entry, leading to improved operational efficiency.

### Cost Reduction

By consolidating multiple services, overall system costs can be optimized. Additionally, reducing human error lowers indirect operational costs.

### Visibility

Real-time tracking of inventory and order status enables faster decision-making. Centralized data management improves consistency and accuracy.

### Reliability

Built on AWS infrastructure, the system ensures high availability and scalability, along with fast support response to minimize downtime.

---

## 3. System Policy

This section defines the fundamental design and operational principles.

### Technical Approach

The system is developed as a web application accessible via the internet. AWS is used as the infrastructure platform to ensure scalability and reliability. A multi-tenant architecture enables usage by multiple companies.
